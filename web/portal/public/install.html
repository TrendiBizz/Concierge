On iPhone or iPad: install from Safari

This browser on iPhone cannot add a web app to the Home Screen — Apple only allows Safari to do it. No website can change that, and no web page can start the install by itself.

This is the Share button — in Safari's bottom bar (top right on iPad).
  1. Tap the Share button — the square with the arrow, in the bottom bar on iPhone (top right on iPad). If you cannot see the bar, swipe up on the page once.
  2. Scroll the list and tap Add to Home Screen.
  3. Leave Open as Web App on, then tap Add.

Not in Safari? If you see “another browser” around the address bar, or you opened this from Instagram, Facebook, WhatsApp, LinkedIn or TikTok, tap ⋯ there and choose Open in Safari, or tap “Copy the link for Safari” and paste it into Safari yourself.

No Share button anywhere on screen? If the address bar has no toolbar at all, you are in a link preview inside another app. Tap ⋯ and choose Open in Safari, or open Safari and paste this address: concierge.trendibizz.com/studio/install

Share sheet without “Add to Home Screen”? Scroll to the bottom of that sheet, tap Edit Actions… and switch Add to Home Screen on.
