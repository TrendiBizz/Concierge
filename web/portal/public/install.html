Your browser can install Concierge straight from this page. No app store, no download.

Open without installing

On iPhone or iPad: three taps in Safari

  1. Open this page in Safari (not the Instagram or Facebook browser).
  2. Tap the Share button — the square with the arrow pointing up.
  3. Scroll and tap Add to Home Screen, then Add.

Apple does not let a web page start the install itself. Those taps are the only way, and they give you the same full-screen app.

Install from the browser menu

This browser has not offered its own install button, but it can still install the app. Open the browser menu and choose “Install app” or “Add to Home screen”.
