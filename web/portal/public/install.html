Easiest: install with the Concierge icon file

Five taps, about 30 seconds. Do this in Safari.

  1. 1Tap the button below.
    Download Concierge iconYou should see: “This website is trying to download a configuration profile. Do you want to allow this?”
  2. 2Tap Allow.You should see: “Profile Downloaded. Review the profile in Settings app if you want to install it.” Tap Close.
  3. 3Open the Settings app (the grey gear). Tap Profile Downloaded near the top, under your name.Can’t see it? Go to Settings → General → VPN & Device Management → tap Concierge.
  4. 4Tap Install (top right), type your phone passcode, then Install again and Done.You should see “Not Verified” in red. That is normal: we do not pay Apple for a signing certificate. The profile only adds the icon and changes nothing else.
  5. 5Go to your Home Screen. The purple Concierge bell is there. Tap it.The app opens full screen and asks for the six-digit code we email you.

To remove it later: Settings → General → VPN & Device Management → Concierge → Remove Profile.

Prefer not to use a profile? Add it from the Share menu instead
This is the Share button — in Safari it is in the bottom bar (top right on iPad). On newer iOS it can be under the ⋯ button instead.
  1. 1Tap the Share button — the square with the arrow, in the bottom bar on iPhone (top right on iPad). If you cannot see the bar, swipe up on the page once.
  2. 2Scroll the list and tap Add to Home Screen.
  3. 3Leave Open as Web App on, then tap Add (top right).

You should see: a purple bell icon named “Concierge” on your Home Screen. Tap it to open the app.

No Share button anywhere on screen? If the address bar has no toolbar at all, you are in a link preview inside another app. Tap ⋯ and choose Open in Safari, or open Safari and paste this address: concierge.trendibizz.com/studio/install
