What this does not check

  • Not an enterprise red-team or full application penetration test
  • Not a PCI, ISO or cyber-insurance compliance audit
  • Not destructive testing, social engineering or physical security
  • Not a guarantee your site cannot be hacked afterwards
  • Not scare-copy that invents urgency you do not have

Data handling: the check fetches the public homepage and a short list of common paths from Trendi’s server (when the API is available). We return status codes and header presence. We do not store the sites you check beyond what the request needs to return a result. Server-side checks are rate-limited (about 5 per IP per hour). Browser-only fallbacks may apply if the API is unavailable.

What we test (before you run)

This tool is not a penetration test. It is a light public check that looks only at whether each item is present or absent. It sends no exploit payloads, makes no login attempts and runs no authenticated tests. Paid penetration testing is a separate scoped service with a written USD quote.

CheckWhat it meansHow results are labelled
Homepage HTTPS Whether the final homepage URL uses https:// and responds. Pass if reachable over HTTPS · Review if not
Security headers HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy on the homepage response. Short values shown in full; long CSP can be expanded. Pass when present · Review for missing HSTS on HTTPS · Info for other missing optional headers
Sensitive paths Whether /.env or /.git/config answer publicly. These must never be on the open web. Pass if blocked or not found · Review if they respond
Common admin paths Whether /wp-admin/ or /admin/ answer. Often a login page. We do not try passwords. Pass if not found or auth-blocked · Review if something public answers
robots.txt & sitemap.xml Whether the usual crawl files respond. Useful context, not a vulnerability score. Info either way for this security tool

After you run

Findings are grouped as Pass (looks fine for this light check), Review (worth fixing or confirming with your developer), and Info (context only). Short header values such as X-Frame-Options and X-Content-Type-Options are shown in full; long Content-Security-Policy values can be expanded.
