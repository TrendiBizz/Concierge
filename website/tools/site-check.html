What is a site snapshot?

A site snapshot is a quick read of public signals on a URL you enter: HTTPS status, whether robots.txt looks open to major crawlers, whether a sitemap is reachable, and the homepage title, description, H1, canonical and JSON-LD types. It is not a ranking report or an AI-mention check.

When a PageSpeed Insights key is configured on our server, we also show lab scores. Otherwise you get a deep link to Google’s tool.

What this checks

  • HTTPS / response status for the URL you enter
  • robots.txt for Googlebot, Bingbot, OAI-SearchBot, PerplexityBot, Claude-SearchBot
  • Sitemap present or missing (URL count capped so the tool stays fast)
  • Title, meta description, H1 count, canonical, JSON-LD types on the homepage HTML
  • PageSpeed via API when configured, otherwise a deep link to PageSpeed Insights
  • llms.txt present or absent. Optional file only. Google Search ignores it for rankings and AI Overviews

What the results mean

Each row is a public technical signal, not a ranking or mention score.

  • HTTPS / status: the URL responds over HTTPS. A non-200 status means fix hosting or redirects before worrying about SEO copy.
  • robots.txt: whether Googlebot, Bingbot and named AI search crawlers look allowed at the root. Blocked means the Indexed door is shut for that bot.
  • Sitemap: reachable or missing. Missing is not fatal, but it slows discovery. Counts are capped so the tool stays fast.
  • On-page (title, description, H1, canonical, JSON-LD): whether the homepage HTML has the usual indexable basics. Missing pieces are fixable page work, not a rank promise.
  • PageSpeed: lab score when our API key is configured, otherwise a deep link to Google’s tool. Lab ≠ field rankings.
  • llms.txt: present or absent only. Google Search ignores it for rankings and AI Overviews.

A clean snapshot means the public basics look reachable. Indexed, Found and Mentioned are still separate outcomes — see AI visibility.

Next steps

  1. If robots.txt blocks a search crawler you care about, fix that first, then re-check.
  2. If the sitemap is missing or broken, publish a valid one and link it from robots.txt.
  3. If the homepage lacks an indexable title or a single clear H1, fix the page next.
  4. Only then work on AI-answer readiness — engines cannot cite what they cannot read.

FAQ

What do site snapshot results mean?

Pass-style signals mean public crawl basics look reachable. They are not your Google ranking list and they do not check whether ChatGPT or Perplexity mention you.

What should I do after a site snapshot?

Fix blockers top-down: robots, sitemap, then homepage title/H1/canonical. Re-run this tool, then use Search Console or Bing Webmaster Tools for engine-side confirmation.

Does green mean I will rank or get an AI mention?

No. Crawl readiness is step one only. We do not promise rankings or AI mentions. Mentions and links are different outcomes.

Sources and limits

Robots rules follow the public robots.txt protocol. PageSpeed scores, when shown, come from Google's PageSpeed Insights API and are lab measurements for that run, not field rankings. Sitemap counts are capped. Browser CORS can block a direct fetch; paste mode exists for that case. We do not store the sites you check beyond what the request needs to return a result.
