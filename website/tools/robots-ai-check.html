Search vs training vs user-triggered bots

Search crawlers (Googlebot, Bingbot, OAI-SearchBot, PerplexityBot, Claude-SearchBot, Amazonbot) fetch pages for search or answer indexes. Training bots (GPTBot, ClaudeBot, Google-Extended, Applebot-Extended, CCBot, Bytespider, Meta-ExternalAgent) are a separate policy choice about model training or grounding. User-triggered agents (ChatGPT-User, Claude-User, Perplexity-User) fetch when a person asks; several vendors say robots.txt may not apply to those requests. Allowed at the root is crawl readiness only, not a mention or ranking promise.

How do I allow OAI-SearchBot in robots.txt?

Direct answer: Publish a User-agent: OAI-SearchBot group with Allow: /, or remove a blanket Disallow: / that applies to it. OAI-SearchBot is OpenAI's search crawler. Why does AI crawler access matter?

AI crawler access matters because search and AI answer systems that fetch the live web need robots.txt permission before they can read your pages. Block Googlebot, Bingbot or an AI search crawler at the root and the Indexed step fails. Open access does not guarantee a mention; it keeps the door open.

Training crawlers are a separate policy choice from search crawlers.

Search crawlers vs training crawlers

This tool lists both groups so you can see the difference. Googlebot and Bingbot support classic search indexing. OAI-SearchBot, PerplexityBot and Claude-SearchBot are the search-oriented bots published by those AI products. GPTBot, ClaudeBot and Google-Extended are closer to training or grounding policy. Allowing search crawlers does not require allowing training crawlers, and blocking training crawlers does not fix a broken index if Googlebot is disallowed.

What the results mean

Allowed means the matched group has no Disallow rules. Blocked means the homepage (/) is disallowed and the group has no Allow rules. Partial means the group has some Disallow rules but is not fully blocked, so check which paths are affected. Unknown means no group matches this bot and there is no * group, so the file gives no answer.

This check is a static, client-side read for humans, not a live crawl guarantee. Publish clear rules either way.

Limits and honesty

When you enter a domain, Trendi's server fetches only https://that-domain/robots.txt: public sites only, up to 512 KB, plain text only, at most 3 redirects on the same site. The fetched file is cached for 10 minutes. Paste the file instead if the site blocks the fetch or serves it in another format. Path rules are read using RFC 9309 matching, where the longest matching path wins and Allow wins a tie. The label summarises the homepage and whether path rules exist, so check specific paths in the file. A green Allowed result does not mean the page is indexed, ranked or mentioned in AI answers. llms.txt is unrelated to robots.txt and is not a ranking lever for Google Search.
