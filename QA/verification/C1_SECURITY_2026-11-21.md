# C1 — Critical Security Vulnerabilities Patch (2026-11-21)

Source of truth: `~/Reports/neon-improvements/report.md` (Section 4, Tier 0 — C1).

## Cause

Six security defects were identified in the audit:
1. **Cross-tenant IDOR (`GET /owner/billing/invoices`):** `api/app/platform_billing.py` queried `platform_invoices` without a `WHERE tenant_id=$1` filter, exposing every tenant's platform invoices, customer emails, amounts, and receipt tokens to any authenticated owner.
2. **Stored XSS (`GET /receipt/{token}`):** `api/app/platform_billing.py:invoice_html` interpolated `customer_name`, `business_name`, `customer_email`, `description`, `number`, and `currency` directly into HTML without `html.escape()`.
3. **Unbound 6-digit login code (`POST /owner/auth/code/verify`):** `api/app/routers/owner_signin.py` passed `body.code` to `owner_auth.accept_invite()` without verifying `email == clean_email(body.email)` or `purpose == 'code'`, allowing cross-email redemption and weakening rate-limiting.
4. **Outbound webhook SSRF (`api/app/portability.py`, `api/app/events.py`):** Tenant CRM and lead webhooks posted directly via raw `httpx.AsyncClient.post()` without HTTPS-only / global-IP DNS validation, IP pinning, or redirect blocking, allowing requests to loopback, RFC1918, container services, or cloud metadata endpoints.
5. **Missing security headers on Studio & public HTML:** `/studio/*`, `/quote/*`, `/invoice/*`, `/receipt/*`, `/privacy`, `/guide/*`, `/upload/*`, `/owner-ui`, `/onboarding`, `/admin-ui`, `/demo/*`, and `/report/*` lacked `Content-Security-Policy`, `X-Frame-Options`, and `Permissions-Policy`.
6. **Unrevoked sign-out token (`web/portal/src/App.tsx`):** Clicking "Sign out" cleared `localStorage` without calling `POST /owner/auth/logout`, leaving bearer sessions valid server-side until expiry.

## Fix

1. Scoped `GET /owner/billing/invoices` in `api/app/platform_billing.py` with `WHERE tenant_id=$1`.
2. Escaped all untrusted fields in `platform_billing.invoice_html()` with `html.escape()`.
3. Updated `owner_auth.accept_invite()` to accept `expected_email` and `expected_purpose` (filtering SQL and verifying in Python, and rejecting `purpose='code'` on link redemption paths). Updated `owner_verify_code()` in `api/app/routers/owner_signin.py` to normalize `body.email` and enforce both `expected_email` and `expected_purpose="code"`.
4. Extended `api/app/public_fetch.py` with `_is_public_ip()` (including IPv4-mapped IPv6 unwrapping), `validate_public_https_url()`, `validate_webhook_url()`, and `post_public()` (HTTPS on port 443 only, no credentials, DNS global-IP verification, IP pinning with `Host` + `sni_hostname`, `follow_redirects=False`, bounded response read). Wired `portability.py`, `events.py`, `routers/crm.py`, and `routers/admin.py` to validate and send exclusively through `public_fetch`.
5. Added CSP profiles, per-request script nonce helper `html_with_script_nonce()`, and `apply_security_headers()` in `api/app/security.py`, applied globally via `owner_boundary` middleware in `api/app/main.py` and route-specific nonce handlers for `/studio/install`, `/upload/{token}`, `/owner-ui`, `/onboarding`, `/admin-ui`, `/owner/social/oauth/callback`, and `/owner/quotations/{id}/print`. Added fallback defensive headers to `scripts/vps/Caddyfile` (`@owner`) and added `scripts/vps/reload-gateway.sh` for safe gateway reload.
6. Added `signOut()` in `web/portal/src/App.tsx` that clears the local token and sends `POST /owner/auth/logout` with `Authorization: Bearer <token>` and `keepalive: true`.

## Proof

- Added `api/tests/test_c1_security.py` covering all six fixes (including real-Postgres IDOR, email-bound code redemption, logout revocation, SSRF rejection across IPv4/IPv6/DNS-rebinding/redirects, XSS escaping, and live CSP/nonce/header checks).
- Updated `api/tests/test_portability.py` to verify pinned HTTPS delivery with `Host` and `sni_hostname`.
- Mutation-checked `test_owner_billing_invoices_is_strictly_scoped_to_callers_tenant`: removing `WHERE tenant_id=$1` caused the test to fail (exit 1); restoring it returned green (exit 0).
- Full API suite: `1600 passed, 42 skipped` against local PostgreSQL (`scripts/dev/test-db.sh`).
- Studio production build (`pnpm run build`) and `oxlint`: exit 0.
- Site SEO contract (`python3 scripts/seo/site_seo.py check`): OK (46 pages).
